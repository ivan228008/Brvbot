# BRV / Сглыпа Smart Moderator

Это улучшенная версия с нормальной постоянной базой SQLite и более умной локальной модерацией.

## База данных

Файл `moderator.db` создаётся автоматически.

Хранится:
- когда чат был активирован;
- пользователи;
- количество сообщений;
- репутация 0–100;
- все нарушения;
- тип правила;
- причина;
- дата;
- наказания;
- последние сообщения для антиспама.

После перезапуска история НЕ пропадает.

## Умная модерация без платного AI API

Бот анализирует не только отдельное запрещённое слово.

Он учитывает:
- комбинацию оскорблений;
- жёсткость оскорбления;
- провокационные фразы;
- негатив + упоминание Павловой;
- одинаковые сообщения;
- скорость отправки сообщений;
- ссылки + рекламные фразы;
- историю нарушений пользователя.

У каждого нарушения есть Smart-score 0–100.

## Исключение Сглыпы

Если пользователь оскорбляет именно бота «Сглыпа»:
`сглыпа ты дебил`

или отвечает непосредственно на сообщение бота с оскорблением —
это НЕ считается нарушением.

## Наказания

Обычные оскорбления:
1. варн
2. мут 6 часов
3. мут 24 часа
4. бан

Спам:
1. варн
2. мут 1 час
3. мут 24 часа
4. кик

Реклама:
1. варн
2. мут 24 часа
3. бан

Павлова:
1. сразу мут 12 часов
2. мут 3 суток
3. бан

Повторы считаются за последние 30 дней.

## Команды

`/activate` — начать историю с текущего момента.
Старые сообщения не учитываются.

`/top` — топ по сообщениям + репутация.

`/stats` — свои сообщения, репутация и нарушения.
Админ может ответить `/stats` на сообщение другого человека.

`/history` — последние нарушения.

`/warn` — ответить на сообщение, ручной варн.

`/mute 60` — ответить на сообщение, мут на 60 минут.

`/ban` — ответить на сообщение, бан.

`/clearwarns` — админ очищает историю нарушений пользователя.

## Установка

1. BotFather -> `/newbot`.
2. BotFather -> `/setprivacy` -> выбрать бота -> Disable.
3. Добавить бота в группу.
4. Сделать админом.
5. Права:
   - Delete messages
   - Ban users
   - Restrict members
6. Запустить `START.bat`.
7. В `.env` вставить:
   `BOT_TOKEN=...`
   `OWNER_ID=твой_числовой_id`
8. Снова `START.bat`.
9. В группе `/activate`.

После `/activate` начинается новая история.
